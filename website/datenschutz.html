Diese Webseite

Die Seite wird von GitHub Pages bereitgestellt (GitHub Inc., USA). Beim Aufruf verarbeitet GitHub technisch notwendige Daten wie die IP-Adresse, um die Seite auszuliefern und vor Missbrauch zu schützen. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an einer sicheren Bereitstellung). Näheres: Datenschutzerklärung von GitHub.

Die Seite setzt keine Cookies, nutzt kein Tracking und lädt keine Schriften oder Skripte von fremden Servern. Um die aktuelle Versionsnummer anzuzeigen, fragt dein Browser einmal bei api.github.com an. Downloads laufen ebenfalls über GitHub.

Das Programm DMNT-Kobold

Das Programm speichert alles nur auf deinem Rechner in Dokumente\DMNT-Kobold. Es liest keine Tasteninhalte und sendet keine Nutzungsdaten. Einmal am Tag fragt es bei api.github.com, ob es eine neue Version gibt. Dabei wird außer der Programmversion nichts übermittelt; GitHub sieht wie bei jedem Abruf die IP-Adresse. Diese Prüfung lässt sich unter Einrichten → System → „Nach Updates suchen“ abschalten.
