DMNT-Kobold

Ein kleiner Begleiter, der auf deiner Taskleiste wohnt.

Herunterladen für Windows

Windows 10 und 11 · kostenlos · ohne Admin-Rechte

Portable-Version · Alle Versionen

Lebt auf der Taskleiste

Er läuft oder hüpft herum, lässt sich packen und werfen und fällt wieder herunter. Alles hinter ihm bleibt anklickbar.

Reagiert auf dich

Er schaut zur Maus, freut sich über einen Klick, schläft ein, wenn du weg bist, und erinnert dich an Pausen.

Lernt Tricks

Erinnerungen, Pausen-Wächter und mehr. Mehrere Kobolde zur Auswahl, jeder mit eigenem Charakter.

Erste Schritte

  1. Herunterladen. Klick oben auf „Herunterladen für Windows“.
  2. Setup starten. Windows kennt das Programm noch nicht und zeigt eventuell „Der Computer wurde durch Windows geschützt“. Dann auf Weitere Informationen und danach auf Trotzdem ausführen klicken.
  3. Installieren. Eine Admin-Abfrage gibt es nicht, der Kobold installiert sich nur für dich.
  4. Symbol anpinnen. Einrichten und Beenden findest du über das Kobold-Symbol unten rechts in der Taskleiste. Windows 11 versteckt neue Symbole hinter dem kleinen Pfeil ^. Zieh das Symbol von dort auf die Taskleiste, dann ist es immer sichtbar.

Fertig, wenn der Kobold auf deiner Taskleiste steht und dich fragt, ob er mit Windows starten soll.

Neue Versionen kommen von selbst: Der Kobold sagt per Sprechblase Bescheid, ein Klick auf „Aktualisieren“ genügt. Deine Einstellungen und Erinnerungen bleiben erhalten.

Datenschutz

  • Keine Tasteninhalte. Der Kobold merkt nur, dass getippt wird, nie was.
  • Keine globalen Tastatur- oder Maus-Hooks.
  • Keine Telemetrie, keine Nutzungszahlen, kein Konto.
  • Einzige Internetverbindung: einmal am Tag die Frage an GitHub, ob es eine neue Version gibt. Dabei wird nichts über dich gesendet. Abschaltbar unter Einrichten → System.
  • Deine Daten liegen sichtbar in Dokumente\DMNT-Kobold, mit täglicher Sicherung. Beim Deinstallieren bleiben sie erhalten.

Gut zu wissen

  • Über Spielen im exklusiven Vollbild kann Windows kein Overlay zeigen. Im Fenster- oder Randlos-Modus bleibt der Kobold sichtbar.
  • Der Quellcode ist offen (MIT-Lizenz). Jeder kann nachsehen, was das Programm tut.
